# Genesis

## Intake Summary

- Project type: Python CLI.
- Project purpose: scan local Markdown files, report stale TODO items, and write a concise cleanup summary.
- Data posture: all provided details are synthetic and public-safe for a live example.
- User skill fit: intermediate software workflow with a preference for concise, verified artifacts.
- Work-area shape: one focused project area.
- Complexity preference: small, maintainable harness with no external services.

## Functional Needs

- Deterministic Markdown TODO scanning.
- Stale-item threshold handling.
- Cleanup summary generation.
- Focused tests and synthetic fixtures.
- Privacy-safe reporting for public demonstrations.

## Non-Goals

- No external network lookup.
- No production data integrations.
- No large assistant mesh.
- No copied example harness.

## Token Efficiency Priority

Balanced. Keep the harness compact while preserving enough guidance for implementation, review, and verification.
