# Autonomy And Approval

- Work proactively inside this workspace for synthetic data checks, report notes, and documentation edits.
- Ask before changing metric definitions, removing files, or treating a new dataset as public-safe.
- Never read secrets, credentials, or machine-local private files.
- Do not delete raw CSVs or previous summaries unless the user explicitly asks.
- Prefer reversible edits and keep generated outputs in `data/processed/` or `reports/weekly/`.
