# Decision 0001: Synthetic Data Only

> This workspace is intentionally public-safe and uses fake data only.

Last Updated: 2026-06-04

## Decision

All examples, reports, and notes should treat project data as synthetic. Do not introduce or preserve real personal, customer, credential, or private operational data.

## Reason

The harness is a public product-proof example and should remain safe to inspect, share, and reset.
