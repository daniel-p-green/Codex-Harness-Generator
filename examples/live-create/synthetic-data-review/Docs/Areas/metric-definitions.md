# Metric Definitions

> Defines metrics used in weekly synthetic summaries so chart notes stay reproducible.

Last Updated: 2026-06-04

## Defaults

- Record count: number of parsed CSV rows in the selected date window.
- Null rate: blank cells divided by total cells for a column or dataset.
- Duplicate rows: exact duplicate full rows unless a stronger key is documented.
- Week-over-week delta: current week metric minus previous week metric, with percent change when denominator is nonzero.

Ask before adding domain-specific formulas.
