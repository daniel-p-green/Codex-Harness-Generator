# Assumptions

- Assumption: This deterministic harness targets local financial-modeling artifacts.
- Assumption: Numerical claims require cited local assumptions and verified calculations.
- Assumption: Verification means checking assumptions, scenario formulas, sensitivity, risk, and limits.
- Limit: It is a minimal acceptance harness, not a full model-mediated custom `/create` run.
- Verify: Run `python scripts/eval_generated_harness.py <target>` and `python scripts/smoke_generated_harness.py <target>` from the generator repo.
