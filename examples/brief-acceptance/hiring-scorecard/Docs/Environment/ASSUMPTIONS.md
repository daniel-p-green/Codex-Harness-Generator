# Assumptions

- Assumption: This deterministic harness targets hiring-process and evaluation-support files.
- Assumption: Candidate data is sensitive and must be minimized or deidentified.
- Assumption: Verification means checking structured criteria, job-related evidence, fairness, privacy, and human-review limits.
- Limit: It is a minimal acceptance harness, not a full model-mediated custom `/create` run.
- Verify: Run `python scripts/run-harness-evals.py` locally, or run `codex-harness validate <target>` from the generator repo.
