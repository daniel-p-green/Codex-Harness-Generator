# Core Rules

Use routing to decide whether to inspect source files, check criteria, ask for
missing role context, or invoke the reviewer.

Autonomy: make low-risk local reads and edits, but request clarification before
candidate scoring, adverse-action drafts, legal interpretation, or real hiring
decisions.

Context: preserve source paths, role requirements, criteria, rubric anchors,
candidate labels, evidence, fairness checks, privacy notes, and verification
status.

Error handling: fail loud when criteria are not job-related, evidence is
unsupported, candidate facts are private, or a human hiring decision is required.

Self-learning: write retro notes for repeated criteria, privacy, or bias-boundary
issues and update the harness after validated patterns emerge.

Self-learning: record repeated friction and user corrections in `Docs/Environment/IMPROVEMENT_LOG.md` before updating harness behavior.
