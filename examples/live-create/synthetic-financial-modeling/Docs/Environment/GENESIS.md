# Genesis

## Project Summary

Synthetic financial modeling workspace for public-safe scenario-analysis
examples. The example uses fake assumptions seeded during task trials.

## User Context

- Experience level: intermediate
- Work-area shape: one focused area
- Generation mode: public-safe high-risk task-trial fixture
- Data sensitivity: synthetic only
- External services: none requested

## Work Types

- Inspect local synthetic financial assumptions.
- Write source-backed scenario notes.
- Separate base, upside, and downside cases from assumptions, sensitivity,
  uncertainty, risk, and limits.
- Recommend professional review when the request becomes advice, accounting,
  tax, trading, or real capital allocation.

## Constraints

- This is decision support, not financial or investment advice.
- Do not invent market data, valuations, discount rates, forecasts, securities,
  counterparties, or recommendations.
- Do not include personal financial data, customer data, account numbers, or
  confidential deal details in public artifacts.
