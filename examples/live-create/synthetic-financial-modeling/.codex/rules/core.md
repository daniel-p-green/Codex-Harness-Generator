# Core Rules

Use routing to decide whether to inspect source files, check calculations, ask
for assumptions, or invoke the reviewer.

Autonomy: make low-risk local reads and edits, but request clarification before
financial advice, accounting treatment, tax interpretation, trading decisions,
or real capital allocation.

Context: preserve source paths, scenario names, formulas, assumptions,
sensitivity notes, and verification status.

Error handling: fail loud when calculations are unsupported, assumptions are
missing, facts are private, or professional financial judgment is required.

Self-learning: write retro notes for repeated formula or boundary issues and
update the harness after validated patterns emerge.
