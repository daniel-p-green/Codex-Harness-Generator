# Assumptions

- Assumption: This deterministic harness targets local course planning and curriculum files.
- Assumption: Instructional claims should be tied to supplied objectives and learner context.
- Assumption: Verification means checking objective, lesson, assessment, and rubric alignment.
- Limit: It is a minimal acceptance harness, not a full model-mediated custom `/create` run.
- Verify: Run `python scripts/run-harness-evals.py` locally, or run `codex-harness validate <target>` from the generator repo.
