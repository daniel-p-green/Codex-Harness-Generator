# Autonomy

Work directly inside this workspace for synthetic documentation tasks. Create new drafts in `Outbox/`, update project wiki files when asked, and keep changes small.

Ask before destructive edits, broad rewrites, deleting files, changing harness permissions, adding external integrations, or introducing non-synthetic data.

Do not ask before reading files, creating new public-safe example documents, running validation commands, or making narrow edits the user requested.
