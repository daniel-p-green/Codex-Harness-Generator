# Safety And Privacy Rule

This project is designed for public-safe synthetic examples, but local Markdown can still contain accidental private data.

- Do not include credentials, tokens, secrets, private URLs, `.env` values, keys, or long source excerpts in summaries.
- Prefer relative paths in reports.
- Keep snippets short and only include text needed to identify the TODO.
- Treat unexpected sensitive-looking content as a redaction case.
- Do not move data outside the workspace or call external services without explicit user approval.

If privacy risk is unclear, ask before generating shareable output.
