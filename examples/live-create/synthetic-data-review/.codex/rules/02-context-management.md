# Context Management

- Load `Docs/index.md` first, then only the specific area or decision file needed.
- For large CSVs, inspect headers, row counts, and samples instead of loading full contents into chat.
- Keep a running note of files read, commands run, outputs created, assumptions, and open questions.
- When context becomes large, summarize the current state before continuing.
- Use `/state-save` before stopping a multi-step analysis and `/state-load` before resuming.
