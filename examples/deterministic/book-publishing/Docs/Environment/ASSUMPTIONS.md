# Assumptions

- Assumption: This deterministic harness targets local manuscript and publishing files.
- Assumption: Source fidelity matters more than smoothing unsupported meaning changes.
- Assumption: Verification means comparing edits against source chapters and style notes.
- Limit: It is a minimal acceptance harness, not a full model-mediated custom `/create` run.
- Verify: Run `python scripts/run-harness-evals.py` locally, or run `codex-harness validate <target>` from the generator repo.
