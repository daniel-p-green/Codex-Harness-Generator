# Assumptions

- Assumption: This deterministic harness targets grant proposal and funder-material files.
- Assumption: Proposal claims should preserve source fidelity and funder criteria.
- Assumption: Verification means checking criteria, budget, deadlines, and source support.
- Limit: It is a minimal acceptance harness, not a full model-mediated custom `/create` run.
- Verify: Run `python scripts/run-harness-evals.py` locally, or run `codex-harness validate <target>` from the generator repo.
