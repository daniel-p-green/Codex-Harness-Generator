## Critical

Every takeaway must trace to a verified number, column, or computed delta.

## Workflow

1. Read the metric summary or checked CSV output.
2. Identify chart purpose, likely chart type, dimensions, and caveats.
3. Draft concise notes: title, subtitle, axis/series labels, takeaways, caveat.
4. Mark any unverified interpretation clearly and ask for confirmation.

## Output

- Title
- Subtitle
- Recommended chart type
- Axis/series notes
- Takeaways
- Caveats
